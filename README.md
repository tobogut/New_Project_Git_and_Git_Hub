# Sample Dashboard

An interactive data visualization dashboard built with [Dash](https://dash.plotly.com/) and [Plotly](https://plotly.com/python/), using the classic Iris dataset.

## Features

- Interactive scatter plot with dynamic axis selection
- Color-coded by Iris species
- Dropdowns to select X and Y axes from all numeric columns

## Requirements

- Python 3.7+
- dash
- plotly
- pandas

## Installation

```bash
pip install dash plotly pandas
```

## Usage

```bash
python test.py
```

Then open your browser and navigate to `http://127.0.0.1:8050/`.

## Dataset

Uses the built-in [Iris dataset](https://en.wikipedia.org/wiki/Iris_flower_data_set) from Plotly, which contains measurements (sepal length, sepal width, petal length, petal width) for 150 iris flowers across 3 species.
